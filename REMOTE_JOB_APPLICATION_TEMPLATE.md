# Remote Job Application Template

## 1. Standard Application Package

For a remote AI / automation role, use:

1. **CV** — upload when the application asks for a resume/CV.
2. **GitHub Portfolio** — provide the portfolio link when a portfolio, website or work sample is requested.
3. **Application Message / Cover Note** — short, tailored to the specific job.
4. **Email** — use `mzawavi@gmail.com` as the professional contact.
5. **WhatsApp** — do not publish publicly; provide only when appropriate or requested by a legitimate recruiter/employer.
6. **LinkedIn** — add later when the profile is ready.
