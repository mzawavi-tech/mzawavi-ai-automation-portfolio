# About This Repository

This repository is a **sanitized portfolio** showing how I approach AI-assisted workflow automation. It contains design write-ups, not deployed systems.

- All examples use **fictional data**. Names, emails, companies and IDs are made up; email addresses use the reserved `example.com` domain.
- Examples are conceptual. They are not extracts of any real project.
- Project descriptions in the main README are high level only.

## Security & Privacy

This repository does **not** include:

- production credentials or `.env` files
- API keys, tokens or webhook secrets
- customer data or personal data of real individuals
- private or proprietary source code
- proprietary business logic
- production URLs or infrastructure details

If you believe something in this repository should not be public, please contact me through my GitHub profile so I can remove it.
